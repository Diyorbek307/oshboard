# OSHBOARD — лендинг

Лендинг умной системы для ресторанов (POS + аналитика + AI) с бэкендом приёма заявок.

## Структура

```
.
├── index.html            # разметка страницы
├── css/styles.css        # все стили
├── js/main.js            # вся клиентская логика (анимации, форма, 3D-hero)
├── assets/               # изображения
├── server/               # бэкенд (Node.js + Express)
│   ├── server.js         #   маршруты и запуск
│   ├── store.js          #   хранилище заявок (JSON-файл)
│   ├── mailer.js         #   отправка на почту (SMTP, опционально)
│   ├── .env.example      #   пример конфигурации
│   └── data/leads.json   #   заявки (создаётся автоматически)
└── package.json
```

## Запуск

Нужен **Node.js 18+**.

```bash
npm install      # установить зависимости (один раз)
npm start        # запустить сервер → http://localhost:3000
npm run dev      # то же, но с авто-перезапуском при правках
```

Сервер отдаёт фронтенд и API на одном порту. Открой `http://localhost:3000`.

> Можно открыть `index.html` и просто как файл (без сервера) — страница работает,
> но форма тогда не отправляется на бэкенд, а открывает почтовый клиент (запасной вариант).

## API

| Метод | Путь | Назначение |
|-------|------|------------|
| `POST` | `/api/lead` | Приём заявки `{ name, phone, place, type }`. Валидирует, сохраняет, шлёт на почту. |
| `GET`  | `/api/leads?token=…` | Список заявок (нужен `ADMIN_TOKEN`). |
| `GET`  | `/api/content` | Контент сайта (новости + контакты). |
| `GET`  | `/api/health` | Проверка живости сервера. |

## Админ-панель

Открывается на **`/admin`** (например `http://localhost:3000/admin`).
Вход по логину и паролю из `server/.env` (`ADMIN_USER` / `ADMIN_PASSWORD`).

Что можно делать:
- **Новости** — добавлять/редактировать/удалять с картинками (загрузка файлов). Появляются блоком на сайте.
- **Тексты сайта** — редактирование **всех текстов на 3 языках** (RU/UZ/EN), с поиском. Пустое поле = вернуть значение по умолчанию.
- **Настройки** — логотип (текст + картинка), телефон, Telegram, Instagram, e-mail.
- **Заявки** — просмотр всех отправленных заявок на демо.

Тексты и переводы: базовые значения — в `assets/i18n-base.json`, правки из админки — в `server/data/content.json` (накладываются поверх базовых).

Безопасность: сессии (cookie `httpOnly`), защита всех админ-маршрутов, лимит размера загрузки (5 МБ, только картинки).
⚠️ Перед публикацией **смени `ADMIN_USER`, `ADMIN_PASSWORD` и `SESSION_SECRET`** в `server/.env`.

Пример:

```bash
curl -X POST http://localhost:3000/api/lead \
  -H "Content-Type: application/json" \
  -d '{"name":"Азиз","phone":"+998901234567","place":"Чайхана","type":"Чайхана"}'
```

Встроено: серверная валидация, ограничение частоты (5 заявок с одного IP в минуту),
защита админ-эндпоинта токеном.

## Почта

Без настройки заявки просто сохраняются в `server/data/leads.json`.
Чтобы они приходили на e-mail — два способа (в `server/.env`):

**Способ 1 — Web3Forms (просто и бесплатно, рекомендуется):**
1. Зайди на https://web3forms.com, введи свою почту → получишь Access Key письмом.
2. Впиши ключ в `WEB3FORMS_KEY` в `server/.env`.
3. Перезапусти сервер. Без паролей и SMTP.

**Способ 2 — SMTP / Gmail (для продвинутых):**
Заполни `SMTP_*` в `server/.env`. Для Gmail нужен **App Password** (не обычный пароль):
Аккаунт Google → Безопасность → Двухэтапная аутентификация → Пароли приложений; порт 465, `SMTP_SECURE=true`.

Файл `server/.env` в git не попадает (секреты).
